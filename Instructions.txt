MATRIX SCREEN SAVER
===================

Digital rain for your Mac.

Requires a Mac with Apple silicon (M1 or later) running macOS 13 or newer.


INSTALL
-------
1. Double-click Matrix.saver in this window.
2. If macOS asks, choose whether to install for just you or for all users.
3. System Settings opens. Choose Matrix from the list of screen savers.

You can eject this disk image once it is installed.


IF MACOS BLOCKS IT
------------------
This screen saver is not notarized by Apple, so macOS may say it can't verify
the developer or that the file can't be opened. To allow it:

1. Click Done (not Move to Trash) on the warning.
2. Open System Settings > Privacy & Security.
3. Scroll down to Security and click Open Anyway next to the Matrix message.
4. Enter your password if asked, then double-click Matrix.saver again.

If the screen saver is installed but won't run, open Terminal and paste this
line, then restart System Settings:

    xattr -dr com.apple.quarantine ~/Library/Screen\ Savers/Matrix.saver


OPTIONS
-------
In System Settings, select Matrix and click Options to change:

Rain

  Preset      Classic, Sparse, Downpour or Slow Drift
  Colour      Classic Green, Cyan, Blue, Purple, Red, Amber, White, a Custom
              hue of your choice, or Colour Cycle, which slowly shifts hue
  Speed       How fast the streams fall
  Density     How many streams are on screen
  Font size   How large the characters are
  Characters  Film, Binary, Latin, Custom (type your own), or Logs, which
              spells out log lines as they fall (see the Logs tab)

Effects

  Depth       Layers of rain: distant streams are small, dim and slow
  Glow        How strongly the characters bloom
  CRT         Faint scanlines and darkened edges, like an old monitor
  Glitches    Now and then a patch flickers or the screen stutters
  Frame rate  15, 30 or 60 frames per second. 15 uses the least power
  Displays    Rain on every display, or on the main display only

Text

  Rain clock        Shows the current time in the rain
  Film intro        Types your text on black before the rain begins
  Hidden messages   Now and then lights up words in a column of rain

For the intro and messages, separate each line or message with a /
Type {name} anywhere to show your first name, e.g. Wake up, {name}…

Logs (when Characters is set to Logs)

  Source      A log file on this Mac, or a Loki server
  Log file    Which file, e.g. /var/log/install.log (the default). New
              lines appear as they are written
  Loki URL    Your Loki server, e.g. http://192.168.1.10:3100
  Services    Tick the services to show, from the list Loki has
  Query       Filled in by Services, or type any LogQL query, e.g.
              {service_name="traefik"} |= "500". Shows the last day of
              lines, then new ones as they arrive
  Keywords    Shown in red (white if the rain itself is red). Separate
              them with commas; case is ignored and "fail" also matches
              "Failed"

Logs can show user names, computer names, addresses or network names, so
mind who can see your screen.


UNINSTALL
---------
1. In Finder, choose Go > Go to Folder and enter:

       ~/Library/Screen Savers

   If you installed for all users, enter /Library/Screen Savers instead.

2. Move Matrix.saver to the Trash.
